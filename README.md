# CCAP — Crypto Capital Dashboard (iPhone PWA)

**نسخه انتشار: 0.9.38**

داشبورد فارسی مدیریت سرمایه و تحلیل بازار برای iPhone؛ قابل نصب از Safari با گزینه Add to Home Screen.

## تغییرات نسخه 0.9.38
- Bitunix USDT Perpetual به‌عنوان منبع اول داده عمومی بازار.
- حفظ منابع جایگزین Binance، Bybit و Gate.io در صورت اختلال Bitunix.
- افزودن پشتیبانی Bitunix برای فهرست بازار، دریافت کندل و نمودار.
- گسترش تحلیل عمیق Cloud Engine به تایم‌فریم‌های ۵ دقیقه، ۱۵ دقیقه، ۱ ساعت و ۴ ساعت.
- Paper Trading تنها حالت اجراست؛ اتصال خصوصی حساب Bitunix و ثبت سفارش واقعی در این نسخه وجود ندارد.

## امکانات
- اسکن زنده بازار چند صرافی و تحلیل چندتایم‌فریم.
- موتور هوشمند تطبیقی در اسکنر.
- پایش ابری روی Cloudflare Workers؛ Cron مستقل از باز یا بسته بودن اپ اجرا می‌شود.
- نمایش آخرین Snapshot و نتایج تحلیل سرور هنگام بازگشت به اپ.
- Web Push برای سیگنال جدید، تغییر جهت و ضعیف‌شدن سیگنال.
- مدیریت ریسک و سرمایه، آرشیو عملکرد سیگنال و Paper Trading.
- کیف پول EVM اختیاری و مستقل از موتور سیگنال؛ انتقال دستی نیازمند تأیید صریح کاربر است.

## نصب و اعلان iPhone
1. [نسخه منتشرشده CCAP](https://mohammadamin2407-wq.github.io/ccap-public-releases/) را در Safari باز کنید.
2. Share → Add to Home Screen را انتخاب کنید.
3. برای اعلان Web Push، برنامه را از آیکون Home Screen باز کنید و تنظیمات کارت Cloud Engine را انجام دهید.

## داده و ریسک
- Bitunix در این فاز فقط برای داده عمومی بازار استفاده می‌شود؛ API Key صرافی لازم نیست.
- هیچ سفارش واقعی ثبت نمی‌شود؛ Paper Trading صرفاً شبیه‌سازی است.
- در صورت اختلال Bitunix، منابع جایگزین در دسترس‌اند.
- امتیازها الگوریتمی و آزمایشی‌اند و تضمین سود یا احتمال موفقیت کالیبره‌شده نیستند.
