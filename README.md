# CCAP — Crypto Capital Dashboard (iPhone PWA)

**نسخه انتشار: 0.9.39**

داشبورد فارسی مدیریت سرمایه و تحلیل بازار برای iPhone؛ قابل نصب از Safari با گزینه Add to Home Screen.

## تغییرات نسخه 0.9.39
- در بخش «گزارش سیگنال‌ها و هشدار تضعیف»، ابتدا فقط ۵ گزارش اخیر نمایش داده می‌شود.
- دکمه «نمایش بیشتر» گزارش‌ها را در دسته‌های ۵تایی باز می‌کند؛ «نمایش کمتر» فهرست را دوباره جمع می‌کند. گزارش‌ها حذف نمی‌شوند و حداکثر ۳۰ رویداد اخیر قابل مشاهده است.
- کش PWA به‌روزرسانی شده تا نسخه جدید در آیفون بارگذاری شود.

## امکانات نسخه
- Bitunix USDT Perpetual به‌عنوان منبع اول داده عمومی بازار؛ Binance، Bybit و Gate.io به‌عنوان منابع جایگزین.
- تحلیل عمیق Cloud Engine در تایم‌فریم‌های ۵ دقیقه، ۱۵ دقیقه، ۱ ساعت و ۴ ساعت.
- اسکن زنده بازار، نمودار کندلی، موتور تحلیل تطبیقی و پایش ابری.
- Web Push برای سیگنال جدید، تغییر جهت و هشدار تضعیف.
- آرشیو عملکرد سیگنال و Paper Trading.

## نصب و اعلان iPhone
1. [نسخه منتشرشده CCAP](https://mohammadamin2407-wq.github.io/ccap-public-releases/) را در Safari باز کنید.
2. Share → Add to Home Screen را انتخاب کنید.
3. برای اعلان Web Push، برنامه را از آیکون Home Screen باز کنید و تنظیمات کارت Cloud Engine را انجام دهید.

## داده و ریسک
- Bitunix در این فاز فقط برای داده عمومی بازار استفاده می‌شود؛ API Key صرافی لازم نیست.
- هیچ سفارش واقعی ثبت نمی‌شود؛ Paper Trading صرفاً شبیه‌سازی است.
- در صورت اختلال Bitunix، منابع جایگزین در دسترس‌اند.
- امتیازها الگوریتمی و آزمایشی‌اند و تضمین سود یا احتمال موفقیت کالیبره‌شده نیستند.
