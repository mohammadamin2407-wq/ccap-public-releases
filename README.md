# Crypto Capital Dashboard — Public Releases

This repository contains public release artifacts and update metadata for CCAP.

## Release layout
- `update.json` — update manifest consumed by the app.
- `releases/v0.9.7/` — release artifacts for version 0.9.7.

## Privacy
Application source code and internal development records remain in separate private repositories. Never commit source code, credentials, API tokens, signing keys, or private user data here.
