# CCAP — Crypto Capital Dashboard (iPhone PWA)

**نسخه انتشار: 0.9.34**

داشبورد فارسی مدیریت سرمایه و تحلیل بازار برای iPhone؛ قابل نصب از Safari با گزینه Add to Home Screen.

## امکانات
- اسکن زنده بازار چند صرافی و تحلیل چندتایم‌فریم.
- حالت انتخاب چند استراتژی و موتور هوشمند تطبیقی در اسکنر.
- پایش ابری روی Cloudflare Workers؛ Cron مستقل از باز یا بسته بودن اپ اجرا می‌شود.
- Snapshot قیمت و حجم تا ۲۰۰ قرارداد پرحجم USDT و تحلیل عمیق ۶ نماد در تایم‌فریم‌های ۵ دقیقه، ۱۵ دقیقه و یک‌ساعت.
- نمایش آخرین Snapshot و نتایج تحلیل سرور هنگام بازگشت به اپ.
- Web Push برای سیگنال جدید، تغییر جهت و ضعیف‌شدن سیگنال؛ مدیریت ثبت اعلان با کلید اختصاصی محافظت می‌شود.
- مدیریت ریسک و سرمایه، آرشیو عملکرد سیگنال و Paper Trading.
- اعتبارسنجی پیوسته همه فاصله‌های کندل ۱ دقیقه‌ای، دریافت دوباره و ارزیابی پس‌زمینه رکوردهای معلق.
- در نبود تاریخچه، Paper Trading فقط با سیگنال تازه معتبر، قیمت مستقل تازه و تأیید کنترل‌های ریسک؛ ورودی‌ها در آمار کندل کامل شمرده نمی‌شوند.
- کیف پول EVM درون‌برنامه‌ای مبتنی بر MPC با ورود چندعاملی، نمایش آدرس و موجودی و انتقال دستی ETH روی Ethereum/Base و شبکه‌های آزمایشی؛ تا زمان ثبت شناسهٔ عمومی ارائه‌دهنده غیرفعال می‌ماند.
- کیف پول از موتور سیگنال و اسکنر جداست؛ نه کلید خصوصی یا عبارت بازیابی در CCAP نگهداری می‌شود و نه سفارش معاملاتی خودکار ثبت می‌شود.

## راه‌اندازی اسکنر ابری
Cloud Engine در مخزن خصوصی CCAP منتشر شده و اسکن زمان‌بندی‌شدهٔ آن مستقل از باز یا بسته بودن اپ اجرا می‌شود. Secretهای Cloudflare و اعلان‌ها در کد عمومی این PWA قرار نمی‌گیرند.

اسکن زمان‌بندی‌شده هر ۲ دقیقه اجرا می‌شود. Snapshot گسترده بازار و تحلیل عمیق کندلی از هم جدا هستند: تا ۲۰۰ نماد در فهرست بازار و ۸ نماد در تحلیل ۵m/15m/1h بررسی می‌شوند. ارزیابی تاریخچه عملکرد پس‌زمینه روی همان Worker موجود اجرا می‌شود؛ Worker دوم ساخته نمی‌شود.

## نصب و اعلان iPhone
1. [نسخه منتشرشده CCAP](https://mohammadamin2407-wq.github.io/ccap-public-releases/) را در Safari باز کنید.
2. Share → Add to Home Screen را انتخاب کنید.
3. برای اعلان Web Push، برنامه را از آیکون Home Screen باز کنید، کلید `CCAP_PUSH_TOKEN` را در کارت Cloud Engine وارد کنید و Notifications را مجاز کنید.

## داده و ریسک
- فقط داده عمومی بازار خوانده می‌شود؛ API Key صرافی لازم نیست و هیچ سفارش واقعی ثبت نمی‌شود.
- در زمان بسته بودن اپ، Worker ابری به اسکن ادامه می‌دهد؛ رابط اپ هنگام باز شدن آخرین Snapshot را دریافت می‌کند.
- امتیازها الگوریتمی و آزمایشی‌اند، احتمال موفقیت کالیبره‌شده یا تضمین سود نیستند.
- در اختلال API، زمان آخرین اسکن و وضعیت stale را بررسی کنید.

## فعال‌سازی کیف پول درون‌برنامه‌ای
برای تنظیم پروژهٔ MetaMask Embedded Wallets و انتشار شناسهٔ عمومی آن، [راهنمای کیف پول](wallet-setup-fa.md) را ببینید. شناسه را در GitHub Actions Variable با نام `VITE_WEB3AUTH_CLIENT_ID` ثبت کنید؛ هیچ Secret، API key صرافی، عبارت بازیابی یا کلید خصوصی در این اپ لازم نیست.

این نسخه فقط انتقال سادهٔ ETH را پوشش می‌دهد. شبکه‌های مجاز Ethereum، Sepolia، Base و Base Sepolia هستند. هر انتقال ابتدا پیش‌نمایش شبکه/آدرس/کارمزد می‌دهد و سپس برای امضا به تأیید صریح کاربر در پنجرهٔ کیف پول نیاز دارد. از شبکهٔ اصلی فقط با مبلغی که از دست‌دادنش را می‌پذیری استفاده کن.
