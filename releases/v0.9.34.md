# CCAP v0.9.34

- Add an optional MPC-backed EVM wallet panel using MetaMask Embedded Wallets, with mandatory MFA and no in-app private-key or seed-phrase handling.
- Add public address and live native balance display, plus a two-step native ETH transfer review and explicit wallet-signature flow.
- Restrict transfers to Ethereum, Sepolia, Base, and Base Sepolia; display chain, recipient, amount, approximate fee, and post-transfer balance before approval.
- Keep wallet signing isolated from the market scanner and Cloud Engine. No exchange keys, automatic transfers, contract calls, or real exchange orders were added.
- Keep the wallet disabled until the public Embedded Wallet Client ID and provider dashboard configuration are supplied through the Pages repository variable.
- Build the PWA with Vite and retain the existing Cloud Engine Worker and scheduled scanner.
